# BMI Calculator

A simple BMI (Body Mass Index) Calculator built using **React.js** to calculate and display BMI based on user input of weight and height.

## Features

- Input fields for weight (kg) and height (cm/m).  
- Calculates BMI and displays category (Underweight, Normal, Overweight, Obese).  
- Responsive design for desktop and mobile.  
- Real-time calculation with user-friendly interface.  

## Technologies Used

- React.js (Functional Components & Hooks)  
- HTML, CSS, JavaScript  
- State management with `useState`  
- Event handling for input changes and button clicks
